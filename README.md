# 🏦 Bank Management System (Desktop App)

A complete Desktop Banking Management System built using **Java**, **Java Swing (GUI)**, and **Microsoft SQL Server (JDBC)**.

## 🚀 Features
- **User Authentication**: Login system for Admins and Employees.
- **Customer Management**: Add, Update, Delete, and View customers.
- **Account Management**: Create Savings/Current accounts for customers.
- **Transactions**: Deposit, Withdraw, and Transfer money between accounts.
- **Transaction History**: View detailed history of all operations from the database.
- **Modern UI**: Built with Java Swing and FlatLaf for a clean, modern look.

## 🛠️ Technologies Used
- **Java (JDK 26)**
- **Java Swing** (GUI)
- **Microsoft SQL Server** (Database)
- **JDBC** (Java Database Connectivity)
- **FlatLaf** (Modern Look and Feel for Swing)

## ⚙️ How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure you have **SQL Server** installed and running.
4. Run the SQL scripts in the `database_script.sql` file (if available) to create the database and tables.
5. Update the database credentials in `DBConnection.java`.
6. Run the `LoginForm.java` file.
